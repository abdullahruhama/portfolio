1. Full Stack Project - "InterPortal"

Tech used:

    BackEnd & Architecture

  • Framework: C#, ASP.NET Core 8 Web API
  • Database: Microsoft SQL Server
  • ORM: Entity Framework Core (EF Core) with Code-First Migrations
  • Design Patterns: RESTful API Architecture, Dependency Injection

    • FrontEnd & UI

  • Framework: Angular (Standalone Components architecture)
  • Language: TypeScript, HTML5
  • Styling: Tailwind CSS
  • Libraries: jsPDF and jspdf-autotable (for client-side document generation)
  • State Management: Reactive forms, RxJS Observables, Component-level state tracking

    • Technical Achievements:

  • Full-Stack Architecture: Engineered a scalable RESTful API using ASP.NET Core and Entity Framework Core to drive a 9-module Angular frontend built with Standalone Components.
  • Database Design: Modeled a highly relational SQL Server database using Code-First migrations to seamlessly manage diverse corporate data streams, ranging from IT helpdesk tickets to HR performance evaluations.
  • Role-Based Access Control (RBAC): Implemented dynamic state management to securely isolate executive data, ensuring reporting dashboards and management actions are restricted to administrative personnel.
  • Client-Side Document Generation: Integrated jsPDF and jspdf-autotable to aggregate live database metrics into formatted, printable executive reports directly in the browser, eliminating server-side rendering overhead.

2. AI-Powered - Dialect Translator

Tech used:
  • ASP.NET Core (C#)
  • Vanilla JavaScript
  • Google Gemini AI
  • Azure App Service
  • GitHub Actions

    • Technical Achievements:

  • Architecture: Built a mobile-first JavaScript frontend that securely consumes a custom C# ASP.NET Core Web API.
  • AI Integration: Engineered backend server prompts using the Google Gemini API to process and return accurate, localized dialect translations and phonetics.
  • Cloud & Automation: Deployed the backend to Microsoft Azure, utilizing GitHub Actions to establish a fully automated CI/CD pipeline.
  • Security: Hardened the API by implementing strict CORS policies and securely managing AI keys within Azure Environment Variables.

3. Machine Learning - Laptop Price Prediction System

Tech used:
  • Python
  • Data Manipulation & Analytics: pandas, numpy
  • Machine Learning & Modeling: Scikit-learn, XGBoost / LightGBM, TensorFlow / PyTorch
  • Deployment & API: Flask / FastAPI, Streamlit

    • Technical Achievements:

  • Data Engineering: Constructed a robust data pipeline using pandas and numpy to clean, normalize, and extract key hardware features from historical laptop datasets.
  • Model Development: Trained and optimized machine learning models leveraging Scikit-learn and XGBoost to accurately forecast laptop prices based on diverse system specifications.
  • Advanced Analytics: Utilized deep learning frameworks (TensorFlow/PyTorch) to capture complex, non-linear relationships and hardware patterns in pricing data.
  • Web Deployment: Developed and deployed an interactive web interface via Streamlit and FastAPI, enabling users to input specifications and generate real-time price predictions.
